# Learning by Design Skills

Reusable Codex skills for reviewing syllabi, learning content, and assessment
instruments through the Learning by Design framework, with particular attention
to learner use of generative AI.

This repository is a skills package rather than a course template. Its skills
produce a review or design brief that separates:

- evidence in the submitted material;
- reviewer inferences and recommendations; and
- source-grounded rationale.

## Skills

| Skill | Use it for |
| --- | --- |
| `learning-by-design-review` | Evaluating learning content, modules, activities, or assessments for pedagogical quality. |
| `learning-by-design-genai-assessment` | Designing or reviewing assessments where learners may use generative AI. |
| `learning-by-design-syllabus-audit` | Auditing a syllabus for learning-design coherence, assessment alignment, and an AI-use policy. |

## Use with Codex

Install each folder in `skills/` into your Codex skills directory, preserving
its contents. For a local installation:

```bash
mkdir -p ~/.codex/skills
cp -R skills/learning-by-design-* ~/.codex/skills/
```

Restart or refresh Codex after installation. Invoke a skill by name, for
example: “Use `learning-by-design-genai-assessment` to review this rubric.”

## Evidence and citation policy

The primary source is available as a free PDF from the
[publisher's book page](https://cgscholar.com/publishers/books/learning-by-design-cd66f668-782d-419d-b59a-561919036943).
It is not distributed in this repository.

Recommended citation (APA 7):

> Kalantzis, M., Cope, B., & Zapata, G. C. (2026). *Learning by design*
> (2nd ed.). Common Ground Research Networks.
> https://doi.org/10.18848/LRNRBI/B65

Source claims in the skills cite printed page numbers, which are seven pages
lower than the PDF viewer page number (for example, printed p. 276 is PDF page
283). See
[sources/learning-by-design-2026.md](sources/learning-by-design-2026.md) for
the citation convention, source map, and full references.

The repository does not assert that any framework item is a universally
applicable rule. Reviewers must state where a recommendation depends on the
discipline, learner group, institutional policy, accessibility needs, or
assessment purpose.

## Scope

The skills are informed especially by the book’s later treatment of assessment,
the Learning by Design framework, and GenAI-mediated language education. The
principles can be adapted beyond language education, but any such transfer
should be identified explicitly in the review.
